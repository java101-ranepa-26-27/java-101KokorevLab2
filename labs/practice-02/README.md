# Практика №2. Студент и отчёт

> Дисциплина: «Разработка клиент-серверных приложений»

## Как получить эту лабу

Текст лабы и автотесты лежат в шаблоне `java101-lab2-template`. Твой репозиторий сделан из
старого шаблона, поэтому сначала забери их к себе.

Открой терминал в папке своего проекта и выполни по очереди:

```bash
git checkout main
git remote add lab2 https://github.com/java101-ranepa-26-27/java101-lab2-template.git
git fetch lab2
git checkout lab2/main -- labs/practice-02 src/test
git commit -m "добавлены лаба 2 и тесты"
git push
```

Проверка: в проекте появился каталог `labs/practice-02` с этим текстом и каталог `src/test` с
автотестами.

> Если на строке `git remote add` написано **«remote lab2 already exists»** — просто пропусти
> эту строку.

## Как завести ветку

```bash
git checkout -b task-2
```

Проверка: в правом нижнем углу IDE (или в выводе `git status`) написано `task-2`, а не `main`.

## Что делаем

Программа спрашивает у пользователя данные студента, считает средний балл и печатает отчёт.

### Студент

У студента есть имя и оценки — целые числа по пятибалльной шкале (2–5).

Студент умеет:

- сообщать **средний балл** — среднее арифметическое своих оценок;
- печатать **отчёт** о себе.

### Ввод

Данные приходят с клавиатуры, по порядку:

1. имя — одна строка;
2. оценки — по одной в строке, **пока не введут `0`**. Ноль — это не оценка, а сигнал
   «ввод закончен»; в список оценок он не попадает.

Пример того, что набирает пользователь:

```
Иванов Иван
5
4
5
0
```

### Отчёт

В отчёте должно быть видно:

- имя студента;
- его оценки;
- средний балл;
- **статус** по среднему баллу.

Как именно выглядит отчёт — на твоё усмотрение, лишь бы всё перечисленное в нём читалось.

Статус определяется так:

| Средний балл | Статус |
|---|---|
| 4.5 и больше | отличник |
| 3.5 и больше | хорошист |
| 2.5 и больше | троечник |
| меньше 2.5 | двоечник |

## Как открыть Pull Request

1. Открой страницу своего репозитория на GitHub и обнови её. Сверху появится жёлтая плашка
   **Compare & pull request** — нажми её.
2. Проверь направление слияния: **base: `main`**, **compare: `task-2`**.
3. В поле **Title** напиши, например, `Практика 2: отчёт студента`.
4. Нажми **Create pull request**.

> Кнопку **Merge** не нажимай.

## Как запустить тесты

Автотесты уже лежат в проекте — в `src/test/java/ru/ranepa/`. Они и задают, что должно получиться.
Запуск из папки проекта:

Windows:

```bash
gradlew.bat test
```

macOS и Linux:

```bash
./gradlew test
```

Первый запуск скачает Gradle и зависимости — это нормально, просто подожди пару минут.

Пока не написан класс `Student`, тесты не соберутся — это ожидаемо. Дальше правь код, пока все
тесты не станут зелёными. Подробный отчёт — в `build/reports/tests/test/index.html`.
